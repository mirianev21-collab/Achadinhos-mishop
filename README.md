# Landing Page — Seleção VIP de Ofertas (WhatsApp)

Página única de alta conversão com estética **Glassmorphism**, paleta vibrante (rosa leve, lilás e branco) e integração nativa com o **Meta Pixel (`453862617588411`)**.

## Estrutura de Arquivos
- `index.html` — Estrutura da página, SEO e tag base do Meta Pixel (`PageView`).
- `style.css` — Estilização Glassmorphism, responsividade mobile e animações fluidas.
- `script.js` — Rastreamento de clique no botão CTA (`Lead` e `EntrarGrupoWhatsApp`) com redirecionamento seguro para o grupo.

## Como hospedar gratuitamente no GitHub Pages
1. Crie um novo repositório no seu GitHub (ex: `ofertas-vip`).
2. Faça o upload dos 3 arquivos (`index.html`, `style.css` e `script.js`) na raiz do repositório.
3. Acesse **Settings** > **Pages** no menu do repositório.
4. Em **Source**, selecione `Deploy from a branch`, escolha a branch `main` (pasta `/root`) e clique em **Save**.
5. Em poucos minutos seu link público estará ativo.
